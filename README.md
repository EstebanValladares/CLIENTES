# Centro de Inteligencia Operativa - Grupo Velas (CLIENTES)

Dashboard ejecutivo y operativo para gestión centralizada de:
- **OBRAS & WBS:** Consulta de presupuestos, frentes, partidas y tarjetas conectadas en tiempo real a Google Firebase Firestore.
- **USUARIOS:** Alta, consulta de puestos y asignación de estructuras operativas.
- **CONTRATISTAS:** Validación de expedientes y registros.

---

## 🚀 Inicio Rápido (1 solo clic)
1. Asegúrate de tener Python instalado con la casilla "Add python.exe to PATH".
2. Da doble clic en **`iniciar_dashboard.bat`**.
3. El archivo verificará e instalará automáticamente cualquier librería faltante (`FastAPI`, `Uvicorn`, `Firebase`, etc.) y abrirá tu navegador en `http://127.0.0.1:8000`.
